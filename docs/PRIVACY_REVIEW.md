## 代码事实与运营期望的差异

- 登录实际只有邮箱密码；手机号、Google 登录未实现。不能在政策中写成已经收集。
- 定位实际读取设备坐标，并传到 Nominatim，`LocationAccuracy.medium` 不代表粗略位置保证。
- 设备位置缓存有效期 30 分钟，但过期不等于删除。未发现一年 GPS 轨迹存储。
- 主要托管韩国 AWS 是运营方确认，未检查 AWS 控制台。图片位于 API 本地上传目录，S3 未接入。
- FCM/APNs、Nominatim、Gmail 意味着不能宣称仅 AWS 或无境外处理。
- FCM 可能传输通知正文及关联标识；没有 Analytics/Crashlytics 包，OS/App 版本的自建采集不能仅凭计划写成事实。
- 安全功能 MVP1 不提供，但预备路由仍注册；上线前应通过发布功能开关关闭并验证。`ciphertext` 字段使用 `convert_to`，不是加密。
- 精确集合地点只向组织者、approved/attended 成员展示。
- 年满 18 岁是产品限制；现有注册 API 自动写 adult_confirmed_at，仍须验收真正用户确认流程。

## 删除功能边界与待确认实现

已实现申请与停用：我的 → 设置 → 账号管理 → 删除账号，注册邮箱 + 当前密码 + 二次确认。
服务器记录 deletion_requested_at，状态 deleting，禁用 push_device；登录、旧 token 的 REST 访问及新 WebSocket 连接受限，向旧连接推送前检查状态。
邮件申请必须从已注册邮箱发出并验证控制权；当前邮箱尚无自动邮件验证，不能依据用户随意输入的地址执行删除。

自动审批拒绝了账号级物理清理补丁，理由是取消活动、改变共享聊天/地点及删除附件会影响其他成员。
因此最终擦除尚未实现或执行；并未删除任何真实账号、活动或图片。
待用户确认的具体方案：保留申请后 1–2 工作日处理窗口；清除个人资料和认证数据；未来活动取消并通知成员；聊天保留至发送满 1 年并去掉资料关联；仅必要举报证据限权保留 1 年；附件跟随其记录删除，失败任务可重试；备份执行独立清理。
