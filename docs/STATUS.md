# DAMUMU 当前项目状态

最后核对：2026-10-02（Asia/Seoul）。本页只记当前事实、下一步和阻塞；完成历史见 Git。代码、迁移和测试结果优先于本页。

## 当前已接通

- 图片流量控制已接通：新活动封面生成最长边 640px 的 WebP 缩略图，新聊天图片生成最长边 320px 的 WebP 缩略图，两者限制为 200 KB；列表和聊天气泡只加载缩略图，进入放大预览后才请求现有原图。媒体文件名使用 UUID 且不会覆盖，`/uploads` 返回一年 `immutable` 缓存。上传只接受静态 JPEG、PNG 或 WebP，不提供视频或 Live Photo 上传。旧媒体没有缩略图时兼容回退原图。数据库需应用 `019_media_thumbnails.sql`。

- 聊天可靠性升级已接通：文字和图片消息使用服务端事务保存，客户端 ID 保证弱网重试幂等；消息历史使用时间与 UUID 复合游标并支持加载更早记录。App 按账号和会话缓存最近消息，离线发送会保留并自动重试；长按消息支持回复、15 分钟内编辑、5 分钟内撤回和带说明举报，举报同时保存相邻消息快照。聊天“+”菜单可选择拍照或相册，图片在设备端后台压缩为最长边 1600px、目标 1.5 MB 的 JPEG 后才上传，消息图片可点击进入手势缩放预览。活动群结束 7 天后只读、180 天后归档，取消活动立即只读。WebSocket 轻量事件通过 PostgreSQL `LISTEN/NOTIFY` 跨 API 实例转发。开发数据库已应用 `018_chat_reliability.sql`。

- Admin 用户管理与活动管理已完成视觉精修：筛选区、表格密度、状态和操作层级统一，列表提供明确的“查看详情”入口。用户详情展示账号资料、信誉、喜欢、活动履历和举报；活动详情展示完整活动资料、排期、成员申请、举报及处置记录，并可直接恢复、暂停、封禁、隐藏或取消。管理员可在任意活动详情中通过待审核申请；审批复用活动人数、满员状态、群成员、站内通知和推送同步逻辑，并写入审计日志。桌面 1348px 与移动 390×844 视口均已用真实开发数据验收。

- 已结束活动支持参与者对活动组织者或同场成员提交一次带标签的喜欢／举报。用户资料显示爱心喜欢数和常用正向标签；活动详情的“发布同类活动／喜欢／举报”及管理页操作改为带间距、可换行的方形按钮。举报进入现有治理数据，同一标签获得至少 3 名不同参与者举报后，组织者的未来活动卡或成员的报名审核卡才显示最高频参与提醒；原始举报数和举报人不公开。开发数据库已应用迁移 `017_post_event_feedback.sql`。

- 用户信息页支持点击头像进入全屏预览，支持缩放、关闭和图片失败兜底。“我的活动 → 我发布的 → 管理详情”支持填写必填取消原因（最多 500 字）并取消活动；详情和列表同步显示取消状态与原因，取消后隐藏取消与审批入口。API 在同一 SQL 事务中保存取消状态、活动群系统消息和有效群成员通知，重复取消不会重复发送；群内通知按“活动取消 / 取消原因”展示，并通过现有 WebSocket/FCM 链路提示同步。使用现有数据库字段，无新增迁移。

- 通知和聊天已接入真实 API：报名时通知组织者，组织者审核报名后通知申请人，Admin 审核活动后通知发布者，后台官方公告通知所有活跃用户，新聊天消息通知其他会话成员。活动创建时自动生成唯一活动群聊，组织者和获批/已签到成员自动加入，退出活动或状态失效后自动离开；用户也可单独退出群聊。消息页展示真实活动群、私信和通知，底部导航、分段和列表均有未读标记；支持右滑已读、左滑退出群聊或删除个人列表项、一键全部已读，通知点击后进入详情。登录后的 Flutter 通过首帧认证 WebSocket 实时接收消息和通知同步事件，断线指数退避重连；FCM 设备注册和服务端投递链路已实现，提供 Firebase 配置后启用后台系统通知。
- Windows 开发启动和 Tailscale PostgreSQL 测试脚本只从环境变量读取数据库密码，不再暂停等待手动输入；可使用 `DAMUMU_POSTGRES_PASSWORD`，启动脚本也支持完整的 `ConnectionStrings__Muda`。`dev.ps1` 会记录 API 和 Admin 的 PID，原窗口关闭后可用 `stop-dev.ps1` 安全停止其进程树。
- 开发数据库已应用 `013` 至 `018`；`019` 待数据库连接可用时应用。活动创建时生成唯一群聊并立即加入组织者，获批/已签到成员随状态同步，可登记 FCM 推送设备，支持会话个人隐藏、主动退出群聊、通知软删除、可靠消息发送和活动群生命周期，并存储活动后喜欢／举报。已通过真实 API 生成 DEMO 批次 `20260921-141112`，包含 20 个注册会员、20 个活动、20 条通过申请、20 条拒绝申请、20 条待审核申请、20 个活动群、10 个私信会话和 60 条消息；登录清单保存在本机 Git 忽略的 `.dev-data/`。
- App 发布页的大分类使用横向 emoji＋文字矩形按钮，窄屏每行两个；默认展示六个精选分类和“其它”，新增大分类可展开。每个大分类下有“其它”小分类，选中后输入最多 15 字；顶级“其它”保留直接输入。开发数据库已应用 `012`，新增大分类由触发器补齐“其它”叶子。`icon_key` 保留，但 App 当前不加载分类插画。
- 发布活动可选一张封面；客户端选设备照片后先缩图，再固定 4:3 裁剪、自动压缩，输出 1280×960 JPEG，最终上传文件最多 1.5 MB。界面明确原图无需预先压缩，并显示处理后大小；裁剪后可预览、水平翻转、更换和移除。API 验证图片并存于本地 `uploads/events`，活动列表和详情返回封面 URL；上传后发布失败会尝试删除未关联文件。
- Web 裁剪器缺少 Cropper.js 资源造成的无裁切框、无法旋转和确认无响应已修复；1.6.2 的 JS、CSS 与许可证随 App 本地提供。头像和活动封面在窄屏或矮屏浏览器中自动使用可伸缩的全屏裁剪页，避免设备模拟视口内的对话框高度溢出；桌面宽屏继续使用裁剪对话框。浏览器隔离组件实测裁切框显示、左旋和确认返回图片；头像上传还补齐了 multipart JPEG 类型，并在上传前新增预览及水平翻转。

- App 五个一级页面保留底部菜单；活动详情、聊天、活动记录、设置和安全中心等子页面顶部提供“回首页”，可从深层页面直接返回首页。发布表单有未保存内容时，切换一级页面、返回或回首页均提示确认。
- 安全中心的“紧急帮助”操作列表只保留通知紧急联系人并分享位置，不再展示 112、119 拨号项；即时危险提示仍说明应联系当地紧急服务。

- App 发布页支持“从过往活动中发布”，本人已发布活动列表及记录详情支持“发布同类活动”；通过带登录态的 UUID 详情请求预填名称、介绍、分类、地区、集合点、人数、预计费用和审核设置，开始/结束日期时间清空后必填。新增文案覆盖中英韩。

- Flutter 可通过 API 完成账号登录、资料与头像、分类和地区加载、单次活动发布、首页及发现活动列表，以及“我的活动”和组织者对待处理申请的批准／拒绝。
- 首页和发现使用 `/activities` Cursor 分页，按创建时间与 UUID 排序；搜索和筛选仅针对已经加载的活动。活动结束时间已过时，App 标注“过去活动”并停用详情报名按钮。
- 活动详情、加入、退出和组织者待审核列表已接入真实 API。待审核报名不计入参加人数；申请可填写备注，任何历史状态都禁止同一用户再次申请。组织者、已通过成员和申请人头像可进入只展示头像与名字的公开用户页，申请列表显示提交时间和备注。
