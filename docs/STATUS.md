# DAMUMU 当前项目状态

最后核对：2026-09-18（Asia/Seoul）。本页只记当前事实、下一步和阻塞；完成历史见 Git。代码、迁移和测试结果优先于本页。

## 当前已接通

- App 发布页的大分类使用横向 emoji＋文字矩形按钮，窄屏每行两个；默认展示六个精选分类和“其它”，新增大分类可展开。每个大分类下有“其它”小分类，选中后输入最多 15 字；顶级“其它”保留直接输入。开发数据库已应用 `012`，新增大分类由触发器补齐“其它”叶子。`icon_key` 保留，但 App 当前不加载分类插画。
- 发布活动可选一张封面；客户端提供相册选择、固定 4:3 裁剪、预览、更换和移除，输出 1280×960 JPEG，最多 2 MB。API 验证图片并存于本地 `uploads/events`，活动列表和详情返回封面 URL；上传后发布失败会尝试删除未关联文件。

- App 五个一级页面保留底部菜单；活动详情、聊天、活动记录、设置和安全中心等子页面顶部提供“回首页”，可从深层页面直接返回首页。发布表单有未保存内容时，切换一级页面、返回或回首页均提示确认。

- App 发布页支持“从过往活动中发布”，本人已发布活动列表及记录详情支持“发布同类活动”；通过带登录态的 UUID 详情请求预填名称、介绍、分类、地区、集合点、人数、预计费用和审核设置，开始/结束日期时间清空后必填。新增文案覆盖中英韩。

- Flutter 可通过 API 完成账号登录、资料与头像、分类和地区加载、单次活动发布、首页及发现活动列表，以及“我的活动”和组织者对待处理申请的批准／拒绝。
- 首页和发现使用 `/activities` Cursor 分页，按创建时间与 UUID 排序；搜索和筛选仅针对已经加载的活动。活动结束时间已过时，App 标注“过去活动”并停用详情报名按钮。
- API 提供活动详情、加入、退出、签到、成员管理等接口，但对应 Flutter 流程尚未完整接通。Admin 通过 API 工作。
- 当前数据库经 Tailscale 访问；开发启动和集成测试脚本使用外部提供的密码。2026-09-18 已对开发数据库按序应用 `010`、`011`、`012`；`012` 后有 7 个需要自定义名称的分类叶子。隔离端口 API 集成测试通过，运行中的旧 API 需重启以加载本次代码。

## 接下来做什么

1. 重启运行中的 API 和 Flutter App，并在真实手机/浏览器上验证相册裁剪、图片预览、发布、列表及详情显示，以及各大分类“其它”输入。自动化覆盖了分类交互和图片处理，但尚未用真实账号上传或发布。
2. 在真实活动列表中刷新 App，确认“过去活动”标记和报名按钮状态。其他数据库环境部署时须按顺序应用 `010`、`011`、`012`。
3. 将 Flutter 的 `EventItem.id` 从整数/hash 改成数据库 UUID 字符串，贯通列表、详情、加入和退出。
4. 以 `GET /events/{id}` 加载真实详情，再接通加入、退出、候补和完整组织者成员管理。
5. 接通通知与活动聊天，随后完成举报、屏蔽、评价和安全会面流程。

## 已知缺口与验证边界

- 活动和地点创建尚未处于同一个数据库事务；失败时可能留下孤立地点。
- 搜索、分类和日期筛选仍仅覆盖已加载页面，尚不是服务端全量筛选。
- Flutter 的活动 ID 仍有旧整数/hash 行为；详情及参与 UI 不能据此宣称真实闭环。
- 用户令牌和管理员静态 API Key 仍属开发阶段方案；头像文件使用 API 本地目录。
- 消息、通知、统计和部分安全治理 UI 仍含演示数据或占位说明。
- 原有注册 Golden 测试引用 macOS 专用字体路径，在 Windows 上不能通过；不要仅为通过测试更新快照。
- 加载失败状态在窄面板中改为紧凑重试按钮，避免文字按钮横向溢出。
- Flutter SDK 锁文件与分析缓存位于用户目录，受限环境运行检查时可能需要允许缓存写入。
- 其他数据库环境的 `010`、`011`、`012` 迁移状态未知；真实账号的“其它”及带图发布尚未验证。封面当前使用 API 本地目录，跨实例共享和持久对象存储尚未接入。
