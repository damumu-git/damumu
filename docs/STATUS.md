# DAMUMU 当前项目状态

最后核对：2026-09-18（Asia/Seoul）。本页只记当前事实、下一步和阻塞；完成历史见 Git。代码、迁移和测试结果优先于本页。

## 当前已接通

- App 发布页使用七张可爱插画的大分类卡片，窄屏每行三个；默认展示六个精选分类和“其它”，新增大分类可展开。内置七类在旧 API 未返回 `icon_key` 时也按分类代码加载插画；选择“其它”时小分类改为最多 15 字的文本输入。API、Admin 和数据库已配套更新。

- App 五个一级页面保留底部菜单；活动详情、聊天、活动记录、设置和安全中心等子页面顶部提供“回首页”，可从深层页面直接返回首页。发布表单有未保存内容时，切换一级页面、返回或回首页均提示确认。

- App 发布页支持“从过往活动中发布”，本人已发布活动列表及记录详情支持“发布同类活动”；通过带登录态的 UUID 详情请求预填名称、介绍、分类、地区、集合点、人数、预计费用和审核设置，开始/结束日期时间清空后必填。新增文案覆盖中英韩。

- Flutter 可通过 API 完成账号登录、资料与头像、分类和地区加载、单次活动发布、首页及发现活动列表，以及“我的活动”和组织者对待处理申请的批准／拒绝。
- 首页和发现使用 `/activities` Cursor 分页，按创建时间与 UUID 排序；搜索和筛选仅针对已经加载的活动。活动结束时间已过时，App 标注“过去活动”并停用详情报名按钮。
- API 提供活动详情、加入、退出、签到、成员管理等接口，但对应 Flutter 流程尚未完整接通。Admin 通过 API 工作。
- 当前数据库经 Tailscale 访问；开发启动和集成测试脚本使用外部提供的密码。2026-09-18 已对开发数据库按序应用 `010_activity_cursor_index.sql` 与 `011_illustrated_other_category.sql`；列、约束、索引与分类种子已核验，运行中的 API `/activities` 和 `/categories` 均正常返回。

## 已知缺口与验证边界

- 活动和地点创建尚未处于同一个数据库事务；失败时可能留下孤立地点。
- 搜索、分类和日期筛选仍仅覆盖已加载页面，尚不是服务端全量筛选。
- Flutter 的活动 ID 仍有旧整数/hash 行为；详情及参与 UI 不能据此宣称真实闭环。
- 用户令牌和管理员静态 API Key 仍属开发阶段方案；头像文件使用 API 本地目录。
- 消息、通知、统计和部分安全治理 UI 仍含演示数据或占位说明。
- 原有注册 Golden 测试引用 macOS 专用字体路径，在 Windows 上不能通过；不要仅为通过测试更新快照。
- 加载失败状态在窄面板中改为紧凑重试按钮，避免文字按钮横向溢出。
- Flutter SDK 锁文件与分析缓存位于用户目录，受限环境运行检查时可能需要允许缓存写入。
- 其他数据库环境的 `010`、`011` 迁移状态未知；真实账号的“其它”发布尚未验证。
