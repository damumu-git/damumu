# 搭慕 UI 预览

两个独立入口，无需启动 API、数据库、Flutter、Vite 或静态文件服务器。将整个
`preview` 文件夹保留在一起，在 Chrome / Edge 中直接打开：

- **App**：`app/index.html`
- **Admin**：`admin/index.html`

App 入口使用文楷 Lite 中文、文楷 KR 韩文和 Ysabeau Office 英文/数字；字体已内嵌，
不需要本机安装或联网。Admin也使用相同字体组合。详见 [App 字体说明](app/FONTS.md)。

也可以在本机文件管理器中双击对应文件。不要只复制一个 HTML 文件，入口引用了
同目录的 JS 和 `shared/` 中的共用样式、运行逻辑。没有 npm 安装或构建前置步骤。

## 本轮范围

按 2026-10-26 拉取的 `origin/main`（`271f4b7`）实际业务页面整理：App 47 个、Admin
24 个入口（新增图标素材管理预览），包含主页面、详情、表单、说明页及可独立访问的弹窗 / 底部面板。
完整来源见 [PAGES.md](PAGES.md)。这不是将原界面截图或逐像素搬到 HTML，而是保留业务
字段和能力边界的第一版可交互设计稿，尚未得到视觉方向确认。

- App：认证、五个主导航、活动详情、报名及状态、发布三步、封面编辑界面、复制发布、
  我的活动、组织者审批、取消、成员资料、活动后反馈、聊天、通知、消息操作、图片预览、
  头像选择、语言、注销、外部处理和安全中心等。
- Admin：实际十个栏目，用户 / 活动详情，分类 / 地区新建与编辑，公告，账号 / 活动 /
  举报 / 警报处置及删除确认等。
- 实际为占位或仅说明的功能继续标注，包括地图、安全会面、设置说明、信誉记录和
  屏蔽记录。不额外添加实际不存在的支付、找回密码或管理员登录页面。
- 正式 App 有三语；本预览先维护中文，语言选择页仅演示控件，不假称已经翻译整套。
- 费用是预计线下人均支出；精确集合点按参与状态展示；14岁注册确认、外部服务默认停用、
  三个月保留等业务边界保持明确。

## 如何评审和微调

1. 左侧页面目录可搜索；页面可通过 `#event` 等链接直接定位。手机窄屏时目录位于顶部。
2. 页面内按钮模拟业务跳转。弹窗也列成单独预览入口，方便直接评审其字段和操作。
3. 顶部状态选择器可切换正常、加载、空数据、失败；错误状态中的重试返回正常预览。
   为方便视觉检查，所有页面均能使用这四种通用状态，并不表示所有正式页面都需请求 API。
4. “主题微调”默认浅蓝色（2026-10-27），可切换浅蓝、森林绿、陶土，调整主色、背景、圆角、字号和留白。
   App 还可以调整 320–480px 的设备画布宽度。实际浏览器窄于所选宽度时会自动缩小。
5. App / Admin 分别存储主题参数；禁用本地存储时仍可使用，但刷新后不保留设置。
   导出主题 JSON 后可以作为后续修改正式主题的依据。它不会自动修改 Flutter / React。
6. “重置演示”刷新当前入口，清除内存中的模拟业务操作；主题参数单独使用“恢复默认主题”。
7. 提反馈时提供入口、页面名 / hash、当前主题和修改点，例如：
   “App #event 的标题小一点，卡片圆角 12px；Admin #users 的行间距再紧凑一些”。

表单仅模拟核心流程。分类 / 地区编辑只演示名称保存；上传只验证界面必填，不执行正式
文件校验；头像、裁剪、翻转、相机、语言和反馈等不等同于生产实现。图片选择仅使用本地
FileReader，未上传；裁剪需要在正式 Flutter 页面中完成。示例数据和统计均为虚构，
正式生产目录仍以 API 为准。刷新会丢弃演示消息和业务操作，不应输入真实账号、密码或个人数据。

## 文件分工

```text
preview/
├── app/
│   ├── index.html       # App 入口
│   └── app.js           # 页面目录、页面内容、模拟操作
├── admin/
│   ├── index.html       # Admin 入口
│   └── admin.js         # 页面目录、页面内容、模拟操作
├── shared/
│   ├── preview.css      # 组件样式、布局、响应式与主题变量
│   └── preview.js       # 共用组件、目录、状态切换、主题调节
├── PAGES.md             # 页面到现有源码的对照清单
└── check.cjs            # 离线 DOM 验证，非预览运行依赖
```

没有 CDN、外部字体、远程图片、fetch、XHR 或 WebSocket。入口 CSP 使用 `connect-src 'none'`
阻止接口连接，所有脚本均为本地经典脚本以支持 `file://`。图片为内联 SVG 几何插画及
Emoji。更换真正活动图时优先放在相应入口的 `assets/` 目录，使用相对路径。

## 与正式发布的关系

2026-10-27 已把浅蓝主题及主要组件布局同步到正式 Flutter App 和 React Admin，
对应实现和验证方式见 [UI_PREVIEW_SYNC.md](../docs/UI_PREVIEW_SYNC.md)。API、数据库及
部署脚本不涉及本次设计同步。现有 `deploy/compose.yaml` 的
构建上下文分别为 `../restapi`、`../admin` 和 `../website`，因此根目录下的 `preview/`
不会进入这些 Docker 镜像。AWS 拉取仓库时会得到预览源码，但不需要发布或运行它。

正式页面保留实际 API 联动，按原方式构建发布。后续更新设计或业务代码时，需同步维护
预览与正式主题；HTML 与 Flutter / React 并不是自动双向同步的设计系统。

## 验证

预览本身无需安装依赖。开发者可在仓库外临时安装 `jsdom@29.1.1`，然后执行：

```powershell
node preview/check.cjs C:/path/to/node_modules/jsdom --inventory
```

检查覆盖全部入口、四种状态、链接、主题、搜索、核心表单与模拟业务流程；`--inventory`
重建页面清单。检查使用 DOM 实现，不启动浏览器或服务，不能替代实际视觉验收。
浏览器工具禁止访问 `file://`，本轮没有绕过限制启动服务器；真实浏览器中的排版、字体、
窄屏和图片效果需通过本机直接打开确认。
