# 搭木木（DAMUMU）活动网页版

`www.damumu.com` 使用独立 HTML、CSS 和 JavaScript，与 Android 和 iOS 共用账号、活动、地区、分类和消息 API。测试期间先通过网站访问验证，再进入应用。进入后可搜索、筛选和查看公开活动，登录后可报名、退出、发布、查看记录，并在会话中发送文字和图片。通过网站入口验证后仍需单独登录搭木木账号。

## 页面与运营

| 阶段 | 独立页面 |
| --- | --- |
| P0 | 首页、发现、活动详情、周末指南、账号、发起活动、我的活动、组织者工作台、会话、公开主页、帮助、安全及社区规则 |
| P1 | 地区与分类专题、指南收藏、通知、签到、活动后评价、账号设置、隐私设置、举报记录、反馈及组织者总览 |
| P2 | 意向征集、小组、关注动态、月历和行政区地图 |

Admin 的「周末指南」支持保存、公开发布、撤下、配置专题及首页推荐。公开用户简介由用户在网页主动填写。通知偏好仅控制本浏览器打开通知中心时的默认视图。地图按用户操作加载 OpenStreetMap，仅传递行政区边界。地区和活动数据来自既有公共 API。

## 本机预览

从仓库根目录运行：

```sh
docker compose -f app-web/compose.yaml up --build
```

浏览器打开 http://127.0.0.1:8083。本地容器可访问公开活动和邮箱登录；注册和网页 OAuth 使用生产同源代理。

## App 下载入口

页脚的「下载 App」指向 `/download`。商店页面发布后，在 `site/site.js` 的 `appStoreLinks` 中填入对应的官方商店链接。每个按钮会在自己的链接配置后显示。

## 服务器部署

从 `main` 发布。新增 SQL 时运行 `damumu-deploy-migration`，流程会先备份数据库，再按编号应用待执行迁移。无新增 SQL 时运行 `damumu-deploy`。参见 [服务器部署指南](../deploy/README.md) 和 [当前交接](../docs/STATUS.md)。

## 网页 Google 和 Kakao 登录

提供方回调地址必须精确匹配：

| 提供方 | 回调地址 | 服务器 `deploy/.env` |
| --- | --- | --- |
| Google | `https://www.damumu.com/api/v1/auth/web/google/callback` | `GOOGLE_WEB_CLIENT_ID`、`GOOGLE_WEB_CLIENT_SECRET` |
| Kakao | `https://www.damumu.com/api/v1/auth/web/kakao/callback` | `KAKAO_WEB_REST_KEY`、`KAKAO_WEB_CLIENT_SECRET`、`KAKAO_APP_ID` |

在 Google Cloud 建立 Web application 类型的 OAuth 客户端，加入对应回调地址。Kakao 在现有原生登录使用的同一 Kakao 应用内启用登录，将对应回调加到使用的 REST API key，并启用该 key 的 Client secret。两种密钥都只填写在服务器配置。配置完成后运行 `damumu-deploy`，分别用提供方测试账号验证首次注册和再次登录。

登录和注册各自提供 Google/Kakao 入口。首次注册须补全昵称、确认年龄和阅读隐私政策。已有第三方账号从注册入口授权时会收到登录提示。邮箱登录可独立记住邮箱，或选择在该浏览器保持登录七天。

## 活动系列、定期计划与我的活动

活动系列由发布者整理场次、供用户订阅，各场独立报名。发布时的「重复频率」另用于创建定期活动计划，可选择每周／每月及场数／截至日期。第一场发布后，从用户菜单的「定期活动计划」逐期确认后续场次，或暂停、恢复计划。后续场次采用分类封面，可发布后更换。我的活动支持文字搜索和按页加载，活动详情为有资格的成员提供群聊入口。

## 活动详情和小组

- 活动列表将预计人均费用放在独立行，等级徽记置于昵称前，等级名称以文字标签展示。个人资料和公开主页可打开阶梯式等级说明。
- 活动群聊入口依据服务端的组织者、参与状态和会话成员权限显示。评价按钮仅向符合服务端资格的用户显示。活动收藏入口和已有活动收藏的展示暂时隐藏。
- 小组列表使用紧凑缩略图。创建时可预览系统或上传封面，自由加入或组主确认的人数上限均为 50 人（含组主）。小组聊天显示最近一条置顶公告。
